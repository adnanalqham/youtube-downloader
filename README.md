# YouTube Downloader

A Windows desktop application built with Python, CustomTkinter, and yt-dlp.

## Features

- Desktop graphical interface
- Available video resolutions
- Estimated file sizes when available
- Download progress, speed, and ETA
- Custom download folder
- FFmpeg integration

## Requirements

- Python 3.12+
- FFmpeg

## Installation

Install dependencies:

    python -m pip install -r requirements.txt

Place ffmpeg.exe and ffprobe.exe in ffmpeg/bin/.

Run the application:

    python app.py
